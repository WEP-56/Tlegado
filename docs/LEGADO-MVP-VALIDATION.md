## 后续修复：搜索/探索日志扰乱终端

用户实测发现网络请求日志直接写入 TUI。根因是 fetcher 的三处 `println!`，普通测试的输出捕获此前隐藏了问题。现改为由宿主控制输出的 `tracing::debug!`，不记录请求 URL 或正文。新增子进程测试以 `--nocapture` 执行 GET、带正文 POST、500 响应及重试，检查 stdout/stderr；该回归及原搜索/发现/阅读/离线缓存端到端测试均通过。


## 后续修复：千源导航、批量管理和后台 panic

2026-09-28：侧栏将逐源发现入口收拢为“探索书源”目录及至多一个当前探索书源。新增名称/分组/URL 筛选、状态筛选、分页/首尾定位、多选、全选筛选结果、统一启停、探索开关与确认删除。批量保存和删除使用 SQLite 事务；游标与多选按书源 URL 保持，删除不触碰书架和缓存。

截图中的第二类终端破坏来自 JavaScript 的阻塞 reqwest 客户端：在 Tokio 异步上下文第一次构造时 panic，原全局 panic hook 又从后台线程执行了终端恢复。现将 java.ajax、java.get 与远程 jsLib HTTP 完整生命周期放在普通线程，多线程 Tokio 在等待时释放工作线程；请求超时 15 秒。后台 panic 写入数据目录 panic.log，由任务错误事件回传 UI；主线程 panic 仍恢复终端并报告错误。

验证结果：workspace 共 160 项测试通过，1 项外网测试默认忽略；根包格式检查、Clippy（-D warnings）、git diff --check 和 debug 构建通过。新增回归覆盖 3,000 源的固定侧栏规模与多尺寸绘制、筛选多选/删除确认、刷新后的 URL 定位、批量状态重启持久化、删除失败整批回滚及命名空间隔离。两个子进程回归分别验证 JavaScript HTTP 首次初始化/重复调用/远程库加载（单线程和多线程运行时），以及捕获后台 panic 后没有终端输出或恢复控制序列。

真实 Windows PTY 使用隔离临时数据目录导入 1,200 个测试书源，按分组筛选并禁用其中 600 个，直接查询 SQLite 确认仅目标组变更。再导入 1 个本地 JavaScript 测试源，搜索经 java.ajax 获取搜索 URL 后返回 1 条书籍、0 个失败，进程继续接受操作且 panic.log 为空。删除弹框取消后 1,201 个源均保留；确认删除筛选的 600 个后剩余 601 个，其余组保持不变。正常退出码为 0，退出时恢复备用屏幕、鼠标与光标。未读写用户实际数据目录。

## 阶段 4：分页、聚合与换源

2026-09-29：用户已实测书源基本兼容。本轮补齐搜索/发现后续分页、同书聚合及候选书源切换。

- 搜索和发现按 `n` 追加后续页，`r` 重试失败或取消的未完成页。每源独立页码；空页或全重复页停止该源续页。换关键词/分类会重建查询，旧任务结果不进入新列表。每源每页最多 200 条，每次查询累计最多 2000 条候选，并发上限仍为 4。
- 同名同作者结果合并，保留候选来源。匹配忽略空白、大小写和作者标签；作者缺失时不跨源合并，书架保存也遵循该边界。
- 搜索/发现或阅读中按 `s` 打开候选书源列表，支持继续搜索、续页和重试。阅读中换源先加载新目录和正文，再提交串行保存，收到保存成功回执后才替换阅读状态。失败或提交前取消保留原书籍、正文及进度。
- 章节映射优先使用规范化后的完整标题，否则按原序号并限制在新目录范围内；不同源正文从章首开始。保留书架分组、候选来源和相关阅读元数据，重启后恢复新源进度。
- 书架写入改为同目录临时文件写完、同步后替换；Windows 文件锁测试验证替换失败不会截断旧文件，临时文件也会清理。退出排空换源提交，未恢复的保存失败会返回错误。

## 阶段 4：本地书籍、分组、规则与偏好

2026-09-29：用户已确认上一轮分页、聚合和换源更新无问题，本轮继续接入以下领域能力。

- 本地 TXT/EPUB 可从首页/书架 `o` 或重复传入 `--import-book` 导入，支持 `--import-only`。复用核心本地书籍 service，在数据目录保存副本，读取目录和正文不依赖网络书源。TXT 保留尖括号原文，EPUB 转成纯文本；重复导入复用已完成的本地缓存，并保留书架进度及分组。
- 书架 `m` 管理分组，支持创建、重命名、确认删除和 `J/K` 排序；`M` 为所选书籍归组或解除归组。非空分组禁止删除；空分组保留导航入口，重命名/排序后按 ID 保持当前分组。延迟到达的阅读进度不会覆盖后续归组。
- 净化规则支持增删改、启停、排序、范围和可编辑原文试算，作用于真实网络和本地正文。支持字面替换与 Rust regex 正则/捕获组替换，不承诺 Java 正则的全部语法兼容。无效规则保存前报错；净化只修改展示，保存位置映射回原文 Unicode 字符偏移。
- 七项阅读偏好与规则、分组通过 SQLite 文档服务持久化，UI 只发出命令并消费保存回执。连续偏好调整在后台按序累计；退出排空命令，未恢复的偏好保存失败作为退出错误报告。

验证结果：领域核心及集成测试 **133 项**、TUI/适配层 **59 项**，合计 **192 项通过**；1 项外网测试仍默认忽略。根包格式检查、Clippy（`-D warnings`）、`git diff --check` 和 debug 构建通过。新增测试涵盖 TXT/EPUB 两章导入、移除原文件后重启阅读、重复导入进度、空文件/损坏 ZIP/不支持格式/超限文件、分组 CRUD 与非空删除、规则排序和非法正则、偏好重启恢复、保存失败/重试/退出、原文位置映射、替换扩展不跳过首行，以及四种终端尺寸的管理弹层。

## 阶段 4：JSON 配置导入与书架增删（2026-09-29）

用户已实测确认 TXT/EPUB、分组管理和偏好保存可用。本轮新增净化规则及排版 JSON 的文件/HTTP(S) 导入，命令行为 `--import-rules` / `--import-layout`，对应页面按 `i`。输入限制 4 MiB、规则最多 500 条；规则按名称/分组/范围合并，结构不合法的整批不落库。正文/标题作用域和未知字段保留；不兼容表达式停用并展示原因。

正则增加断言、固定长度后顾及反向引用；Java 水平空白与原始 Unicode 进度映射有回归测试。受限 QuickJS 支持 `@js:` 匹配替换，执行异常或限额触发时整条规则不应用。尚不提供 Android/Java 宿主接口和完整 Java 正则兼容。

实际二进制在隔离目录 `target/plugins-smoke-20260929` 验证了用户提供的 `readConfig.json`，以及 `3f067eb2.json` 的本地与真实 HTTPS 导入：20 条全部保留，17 条因不兼容语法停用。不能将导入成功视为插件效果完全兼容。排版映射日间颜色、粗体、缩进和间距；其他字段完整保留，像素间距近似为终端行。

网络书不再因试读自动上架，阅读中 `a` 加入并保存当前位置。书架 `x` 后 `y` 确认移除网络书或删除本地导入副本，原始文件保留。旧进度无法复活已移除记录；未上架的换源不触发书架提交。本地副本删除前先持久化书架移除；清理失败会提示并刷新书架。
