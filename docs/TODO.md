# Tlegado TODO

本项目采用两阶段推进：先完成 TUI 演示，再接入 Legado 的书源、解析、存储和阅读业务。演示阶段不依赖真实网络和数据库，使用稳定的演示数据。

当前状态（2026-09-29）：TUI 示例与阶段 4 首个真实闭环已完成。用户已实测书源基本兼容；新增搜索/发现后续分页、同书聚合和候选书源切换。正常启动为真实模式，演示使用 `--demo`。鼠标交互适配与相关验收统一延后至 Legado 完整接入后；未勾选的实现和验收项仍保留为待办。

当前优先级：鼠标交互相关实现与验收统一延后，不阻塞当前键盘操作、演示页面验收及后续领域层接入；已有滚轮支持保留，后续统一完善。
