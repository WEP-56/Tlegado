# Tlegado TODO

本项目采用两阶段推进：先把 TUI 的交互、布局和视觉风格做到满意，再接入 Legado 的书源、解析、存储和阅读业务。阶段一不依赖真实网络和数据库，使用稳定的演示数据；阶段二只在 TUI 验收通过后开始。

## 阶段 0：准备

- [x] 确认 Rust 工具链、Ratatui、Crossterm 和 Tokio 版本
- [x] 创建 TUI 二进制入口与基础模块目录
- [ ] 确定 UTF-8、终端颜色、Unicode 宽度和最小终端尺寸策略
- [ ] 确定应用启动、退出和终端恢复流程
- [ ] 建立演示数据模型：书籍、章节、书源、历史、偏好

完成条件：可以启动一个空白 TUI，退出后终端状态正常恢复。

## 阶段 1：TUI 骨架

- [ ] 实现统一事件循环：键盘、鼠标、滚轮、Resize、Tick
- [ ] 实现全局 `AppState`：路由、焦点、弹层、通知、加载状态
- [ ] 实现 `Action` 分发，不让页面直接处理底层终端事件
- [ ] 实现布局计算和可交互矩形登记
- [ ] 实现全局快捷键：`Tab`、`Esc`、`?`、`/`、`Ctrl+B`、`q`
- [ ] 实现状态栏、快捷键提示、Toast 和帮助弹层
- [ ] 实现侧栏、主体区域和窄终端降级布局

完成条件：页面之间可以切换，焦点明确，键盘操作完整，鼠标点击和滚轮可用。

## 阶段 2：演示页面

- [ ] 首页：最近阅读、快捷入口、统计信息
- [ ] 书架：全部/本地/网络筛选、分组、排序、选中态
- [ ] 搜索：输入框、结果列表、加载态、空状态、错误状态
- [ ] 发现：书源分类和结果列表
- [ ] 阅读器：章节正文、分页/滚动、目录弹层、沉浸模式
- [ ] 历史：历史列表和恢复阅读
- [ ] 书源管理：列表、启停、探索开关、测试状态和 JSON 预览
- [ ] 净化规则：规则列表、启停、匹配预览
- [ ] 阅读偏好：主题、字号、宽度、行距、分页模式等设置

完成条件：使用演示数据可以完整走通“首页 -> 搜索/发现 -> 加入书架 -> 阅读 -> 历史”的流程。

- [ ] 检查加载中、成功、失败、超时和取消状态
- [ ] 检查颜色不足、无鼠标和不支持 Unicode 的降级表现
- [ ] 根据测试反馈调整间距、边框、颜色、选中态和快捷键
- [ ] 记录已确认的视觉和交互规范，冻结 TUI 公共组件 API
